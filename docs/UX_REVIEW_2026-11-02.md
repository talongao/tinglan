# 听澜 macOS 客户端 UI/UX 实机评审（2026-11-02）

评审方式：独立 subagent 用 macOS 辅助功能 + 截图实际操作，覆盖 1180×760 与 900×600。
未登录账号、未删除数据、未修改代码。截图在 `/tmp/ux-review/`。

## P0 阻塞

### P0-1 900×600 下「设置 → 音源」下半页完全不可达
- 位置：设置 → 音源，窗口缩到 900×600。
- 操作：进入音源页，内容区向下滚 10 格。
- 现象：「决策模型配置（可选）」被底部播放条压住，API 地址 / API Key / 保存配置 / 测试连接全部不可见；页面没有任何滚动反应，也没有滚动条。
- 原因：设置内容区没有独立滚动，且没有为播放条预留底部空间。
- 建议：设置内容独立滚动 + 底部 padding；播放条不覆盖内容；窗口过小时给明确提示。
- 截图：`42-settings-900.png`、`43-settings-900-scrolled.png`

### P0-2 全局 Toast 常驻、无关闭，并遮挡播放控制
- 位置：任意页面底部居中的 Toast，压在播放条右侧。
- 操作：点歌曲行「+」加入歌单；等 3 秒、点空白；再触发一次播放失败。
- 现象：「还没有本地歌单，先新建一个」覆盖 标准/词/队列/音量，不自动消失、无关闭、无“新建歌单”入口；播放失败的「播放失败，请重试或选择其他音质。」同样常驻，且正好盖住它建议用户去点的音质按钮；没有重试按钮。
- 原因：Toast 只有文字，没有动作与关闭；位置与播放条控件重叠。代码里 `notify` 设了 3.5s，但实际观感是“常驻”，需要复核重绘时机。
- 建议：5 秒自动消失 + 关闭；带行动按钮（新建歌单/重试）；不要覆盖播放控制；错误改用不挡操作的 inline banner。
- 截图：`21-add-to-playlist.png`、`22-toast-still.png`、`23-toast-after-click.png`、`25-playing.png`

## P1 明显

### P1-1 播放失败后状态不更新、无重试/诊断
- 位置：播放条、队列、收藏/搜索行。
- 现象：进度停在 0:00/0:00，播放键仍是三角形；音源页显示“已登录”；错误只提示“重试或选择其他音质”，没有重试按钮、没有分类（会话失效 / 资源不可用 / 版权）；切到标准音质仍失败。
- 建议：播放失败时播放键进入错误态，显示分类原因 + 重试/重新登录/换音质；未知时长显示 `--:--`。
- 截图：`25-playing.png`、`30-row-play.png`、`39-playing-standard.png`

### P1-2 同一个歌单，卡片写 5 首、详情写 3 首（已核实为真实数据 bug）
- 位置：我的歌单 → 卡片 → 详情页。
- 现象：卡片「来自 华为音乐 · 只读 · 5 首」；详情「3 首」，列表 3 行。
- 核实：DB 中 `playlists.track_count = 5`，`playlist_tracks` 也是 5 行；`librarydb.TracksByID` 只按 ID 在“未合并”集合里查，被 `merged_into` 指向别处的 ID 会被静默丢弃，导致详情少 2 行。违反设计里的 `ResolveTrackID` 要求，队列/收藏也可能受影响。
- 建议：`TracksByID` 走 `merged_into` 解析并去重；顺带修复 `playlist_tracks` 里指向已合并行的 ID。
- 截图：`49-playlists-default.png`、`51-playlist-detail.png`

### P1-3 导入弹窗 960 首 vs 收藏页 942 首，差异无解释
- 位置：我的收藏头部 / 从音源导入收藏弹窗。
- 现象：弹窗「华为音乐 已更新 · 960 首」与页面「共 942 首收藏」同屏，没有说明 18 首差在去重。
- 建议：写清「源 960 首，合并去重 18 首，当前 942 首」。
- 截图：`53-import-dialog.png`、`54-import-900.png`

### P1-4 播放历史空状态：副标题照抄收藏、0 首重复、0 首仍可“播放全部”
- 位置：播放历史（0 首）。
- 现象：副标题「收藏的全部歌曲，向下滚动自动加载」；大号「已加载 0 首」下又一行「已加载 0 首」；中间「已加载全部内容」；「播放全部」仍可点；旁边还有「查看华为历史」。
- 建议：副标题改「最近播放的歌曲」；0 首只保留一个空状态；隐藏播放全部；解释「查看华为历史」。
- 截图：`16-history.png`

### P1-5 搜索默认态直接列出 6 首收藏，无标题/说明
- 位置：搜索页（尚未输入）。
- 现象：搜索框为空，下面直接列 6 首收藏（带“华”徽标），没有“最近播放/猜你喜欢/搜索历史”标题，也没有搜索建议。
- 建议：给区块命名，或默认留空展示热门/历史。
- 截图：`17-search.png`

### P1-6 搜索结果每行固定「-」「+」「心」，“-”语义不成立
- 位置：搜索结果行；只读歌单详情行。
- 现象：未收藏的《完美主义》也显示「-」；只读歌单三行也都有「-」；三个图标都没有 tooltip。
- 建议：按上下文只显示可用操作；只读歌单隐藏写操作或禁用并解释。
- 截图：`18-search-results.png`、`51-playlist-detail.png`

### P1-7 900×600 侧栏只剩图标，无标签也无 tooltip
- 位置：900×600 全局侧栏。
- 现象：中文标签消失，「听澜」「音乐库」也消失；悬停无 tooltip。
- 建议：保留可读标签，或至少 hover tooltip + 可访问名称。
- 截图：`40-900x600.png`、`41-rail-tooltip.png`

### P1-8 900×600 内容被浮动播放条遮挡
- 位置：我的收藏、搜索、我的歌单，900×600。
- 现象：收藏第 4 行只露上半；搜索只完整显示 3 行；歌单卡标题只露上半，副标题完全看不见；搜索框与结果之间约 100pt 固定空白。
- 建议：列表底部留出播放条高度；卡片高度响应式；去掉固定空白。
- 截图：`40-900x600.png`、`44-playlists-900.png`、`45-search-900.png`

### P1-9 设置「关闭窗口时：最小化到托盘」是 Windows 术语
- 位置：设置 → 播放。
- 现象：macOS 没有“托盘”，用户不知道窗口会去哪、怎么找回。
- 建议：改为「隐藏到菜单栏/Dock」并说明恢复方式。
- 截图：`09-settings.png`

## P2 打磨

1. **关于页没有版本号**：只有「非官方 · AGPL-3.0 · Viva 原生迁移中」和「OAuth 身份不属于本项目。」，无版本/build/链接。建议显示版本与项目主页，开发说明折叠。`12-about.png`
2. **设置排版与状态表达**：标签与控件相距约 474pt；「华为音乐 音源 · 已启用」橙色实心胶囊像按钮；决策模型配置裸露给普通用户。建议紧凑两栏、badge 表状态、高级项折叠。`09-settings.png`、`15-sources.png`
3. **搜索信息架构弱**：无列头、无结果数、无来源徽标；无结果只有一行；输入框无清除按钮；副标题「搜索歌曲与艺人」与占位符「搜索歌曲或艺人」不一致。`18-search-results.png`、`56-search-noresults.png`
4. **收藏页重复计数与按钮层级不一致**：「共 942 首收藏」下又有「已加载 942 首」；「播放全部」橙色纯文字 vs 歌单详情橙色实心按钮。`24-favors-again.png`、`51-playlist-detail.png`
5. **外观设置**：12 个主题只有中文名无预览；默认字体是 JetBrains Mono（中文音乐应用很怪）；字号滑杆无刻度/重置。`10-appearance.png`
6. **歌词页空状态弱**：只有很淡的「暂无歌词」，无重试/第三方匹配说明；关闭 X 很淡；「…」按钮只在歌词页出现；封面可点开歌词但无提示。`31-lyrics.png`
7. **音量图标点击/悬停无反馈**：没有菜单、滑杆、静音切换，图标前后一致。`28-volume-menu.png`
8. **音质菜单无勾选、命名摇摆**：菜单「标准音质/无损音质」，按钮「标准/无损」，设置「默认音质 无损」。`27-quality-menu.png`
9. **播放队列**：当前曲只有浅色背景；无计数/总时长；X 常驻且“清空队列”无确认；1180 时最后一项被裁掉；900 重开时首项消失。`33-queue.png`、`46-queue-900.png`
10. **我的歌单**：卡片无 hover；详情页无返回箭头/面包屑；「更新歌单」对只读来源含义不明。`50-playlist-hover.png`
11. **播放条布局**：心形收藏离歌名约 250pt；歌名/歌手无可见入口。`01-initial.png`
12. **导入弹窗无遮罩、无右上角 X**：背景看起来仍可操作。`53-import-dialog.png`
13. **「华」徽标无图例**：收藏有、搜索结果没有。`18-search-results.png`
14. **单击只选中、双击才播放**：单击只出现焦点框，无提示；hover 才出现小播放三角。`29-row-click.png`、`57-row-doubleclick.png`

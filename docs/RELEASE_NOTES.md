- Apple Silicon（M 系列）请选择 `arm64.dmg` 对应版本；Intel 请选择 `x64.dmg` 对应版本（文件名还包含 `unsigned` 标记）。

- 附 `SHA256SUMS`，可用于核对下载文件。Windows x64 提供 `setup-unsigned.exe` 安装包，仍未完成真实登录、播放与桌面交互实机验收；Linux 本次不提供安装包。

本次修复 Windows 安装文字乱码、完成页启动入口与登录临时目录清理；Windows 使用 WebView2 授权窗口自动回调。关闭窗口默认隐藏到托盘，已有设置保留。macOS 补齐完整应用的临时签名及打包后的严格校验。
